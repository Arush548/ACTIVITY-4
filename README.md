# Campus Event Task Board

## Overview
A simple campus event preparation board built with HTML, CSS, and JavaScript. Teams use this starter to practice collaborating: pick a small feature, work on a branch, and share the change with the group.

Open `index.html` in a browser — the core features already work so setup does not take the session.

## Built-in features
- **Display** — shows preparation tasks (seeded with a few examples)
- **Add** — type a task and click **Add**
- **Complete** — mark a task done (or **Undo**)
- **Remove** — delete a task from the list

## Files
- `index.html` — page structure
- `style.css` — layout and completed-task styles
- `script.js` — task list logic (in memory, no frameworks)

## Best for student collab

Work in pairs. Each pair picks one slice, implements it, then opens a PR for review.

### Pair A — UI / feedback
- **Empty-state message** — when the list has no tasks, show a message like “No preparation tasks yet”
- **Remaining-task counter** — show how many tasks are still not completed
- **Improve button labels** — make Complete / Undo / Remove / Add clearer (e.g. “Mark done”, “Delete task”)

### Pair B — interactions
- **Confirmation before deletion** — ask the user to confirm before removing a task
- **Completed-task filter** — add All / Active / Completed controls that filter the list

### Pair C — data
- **Prevent duplicate tasks** — block adding a task whose text already exists (ignore case/whitespace)
- **Save tasks with localStorage** — persist tasks so they remain after a page refresh

### How to collab
1. Start from this starter
2. Create a branch for your pair’s tasks
3. Implement 1–2 items from your pair list
4. Open a pull request
5. Review another pair’s PR
